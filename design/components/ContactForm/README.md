# ContactForm

Form konsultasi di Home (versi ringkas) dan Hubungi Kami: nama, perusahaan, email, WhatsApp, layanan, pesan. Dikirim ke apegale.admin@apegale.com.

- Label selalu di atas input; border `line-strong`; tinggi kontrol 44px.
- Error: border `danger` 2px + ikon + kalimat yang menjelaskan cara memperbaiki. Sukses: pesan `success` "Pesan terkirim. Tim kami membalas di hari kerja berikutnya."
- Selalu sediakan tombol WhatsApp di samping Kirim. Isian pada kartu ini adalah contoh.
