# SectionHeading

Pembuka setiap section: `eyebrow` (KAPITAL, garis `red` 24px) → H2 `heading-2` → intro `body-lg` di `ink-muted`.

- Rata kiri secara default; rata tengah hanya untuk section yang isinya simetris (logo klien, testimoni).
- Satu kata/frasa kunci di H2 boleh disorot dengan `<em>` (`brand-text`). Maksimal satu sorotan.
- Lebar maks. 720px.
