# ServiceCard

Kartu satu layanan: ikon dalam lingkaran `brand-tint`, judul `heading-3`, deskripsi 1–2 kalimat, sub-layanan opsional, link "Selengkapnya".

- Enam layanan resmi, urutan tetap: Broad Expatriate Hosting, Expatriate Formalities, Manpower Supply, Legalitas Perusahaan, Airport Escort, HR System & Consulting.
- Grid 3 kolom desktop / 2 tablet / 1 mobile, gap `space-6`, semua kartu sama tinggi isi.
- Hover: naik 4px + `shadow-raised`. Seluruh kartu boleh jadi link ke Detail Layanan.
- Konsumen memberi: ikon Lucide, judul & deskripsi (ID/EN), daftar sub-layanan, URL.
