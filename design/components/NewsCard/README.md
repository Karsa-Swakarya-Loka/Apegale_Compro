# NewsCard

Kartu artikel untuk News dan Regulasi: gambar 16:9, chip kategori (`Regulasi`, `Panduan`, `News`), tanggal, judul `heading-3` maks. 3 baris.

- Artikel tanpa gambar memakai latar `maroon-deep` (jangan pakai gambar stok acak).
- Regulasi boleh melampirkan PDF (UU, PP, Permenkumham, SE) — tampilkan tombol "Unduh PDF" di halaman detail.
- Homepage menampilkan 3 terbaru.
