# PriceTable

Tabel harga per layanan (permintaan klien: Price List ditampilkan). Header `maroon`, baris unggulan `brand-tint`, angka `tabular-nums` rata kanan.

- Kolom: Layanan (+ keterangan `small`) · Estimasi proses · Harga mulai. Selalu ada catatan kaki: apa yang belum termasuk + tanggal update.
- Muncul di halaman Layanan (ringkasan) dan di tiap Detail Layanan. Semua baris dari CMS.
- **Harga dari klien** (sumber: highlight IG "Price List"); kartu ini hanya struktur. Mobile: tabel bisa digeser horizontal di wadahnya sendiri.
