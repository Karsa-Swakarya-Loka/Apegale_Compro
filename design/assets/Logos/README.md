# Logos

Logo resmi Ape Gale Indonesia dari apegale.com (PNG 1200px, latar transparan). Warna asli: daun gelap `#8c1722` (= `maroon`), daun & titik `#bf1e2e` (= `red`), wordmark hitam.

- `apegale-logo.png` — latar terang (`surface`, `surface-soft`).
- `apegale-logo-on-dark.png` — wordmark putih, daun tetap berwarna; untuk `maroon-deep` dan tema gelap. Dibuat dari file asli dengan mengganti piksel hitam menjadi putih.
- `apegale-logo-white.png` — satu warna putih; untuk di atas `maroon` atau foto.
- `apegale-mark.png` — simbol daun + titik saja; favicon, avatar, ruang sempit.
